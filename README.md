# Библиотека 3D-моделей

Коллекция готовых к печати моделей. Новые проекты раскладываются по категориям:

```text
models/
  <категория>/
    <название-модели>/
      README.md
      <финальный-файл>.3mf
```

В README каждой модели фиксируются назначение, совместимость и важные размеры, состав файлов, параметры печати и сборки. В репозиторий добавляются финальный файл для печати и нужная документация; исходный CAD сохраняется, когда важны последующее редактирование или повторная генерация. Промежуточные версии, дублирующие STL/экспорты, превью и системные файлы проекта не добавляются без отдельной пользы.
