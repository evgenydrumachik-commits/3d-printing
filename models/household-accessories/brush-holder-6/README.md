# Brush Holder 6 — держатель для шести щёток

## Назначение

Компактная планка с шестью открытыми держателями для ручек щёток или других подходящих по размеру предметов. Позволяет разместить их в один ряд. Основание плоское; способ крепления к поверхности выбирается по месту установки. Крепёж в комплект модели не входит.

## Размеры и совместимость

| Параметр | Значение |
|---|---|
| Габариты модели (Д × Ш × В) | 90 × 18,1 × 15 мм |
| Количество держателей | 6 |
| Количество деталей | 1 |

Размеры получены из геометрии 3MF. Совместимость с конкретными щётками, допустимая нагрузка и способ крепления пока не задокументированы; перед печатью проверьте размеры ручек и зазоры.

## Файл

- [brush-holder-6.3mf](brush-holder-6.3mf) — проект для печати с геометрией и сохранённым профилем OrcaSlicer 2.5.2. Внутреннее имя модели: `brush-holder-6-v2.stl`.

## Сохранённые параметры печати

| Параметр | Значение в 3MF |
|---|---|
| Принтер | FlashForge Adventurer 5M Pro |
| Сопло | 0,6 мм |
| Материал | PLA |
| Высота слоя (включая первый) | 0,30 мм |
| Стенки | 4 |
| Верхние и нижние слои | По 5 |
| Заполнение | 22%, gyroid |
| Поддержки | Выключены |
| Brim | Выключен |
| Платформа | Textured PEI Plate |

Откройте 3MF в OrcaSlicer, проверьте профиль принтера и материала, затем выполните нарезку. Параметры взяты из файла, а не из подтверждённого результата пробной печати. Для влажной среды или повышенных нагрузок материал и крепление следует подбирать отдельно.

## Сборка

Модель состоит из одной детали, сборка не требуется. После печати проверьте посадку щёток и закрепите планку подходящим для поверхности способом.
